# Aedan's Playground — session handoff

Paste this file into a new session to resume. The plan is `ROADMAP.md`;
build, run and troubleshooting instructions are in `README.md`.

**Status:** the renderer has moved from 2D quads to **3D geometry and
textures**:
- `gpu::Image` builds mip chains on the GPU, and `gpu::Sampler` reads them
  trilinear and anisotropic.
- `render::Mesh` keeps vertex and index buffers in device-local memory.
- Textures live in one bindless array, and meshes are shaded with
  metallic-roughness PBR and normal maps.
- A glTF 2.0 loader runs in the `AssetManager`: decode on workers, upload
  on the main thread.
- The default demo scene is 3D, with an orbit and fly camera (`--model
  PATH` shows any glTF file). The old sprite demo is `--scene sprites`.
- Screenshot: `docs/gltf-scene.png`.

- Repository `colleenneug/Claude-01`, branch `claude/relaxed-cray-5kc2fl`, no pull request open.
- **Long-term goal (user):** Erebus Cradle (the game in `cpp/`) will be moved
  onto this engine eventually; we are still far from that. Roadmap Milestone 5
  covers the port.
- **Environment:** the cloud environment's setup script now also installs
  `libtinygltf-dev nlohmann-json3-dev libstb-dev`. That change is not yet
  proven in a fresh session: if configure cannot find `tiny_gltf.h`, install
  them by hand (the full list is in `README.md`).
- Standing guidelines:
  - modern C++20 (smart pointers, RAII, `std::span`, designated initialisers);
  - no over-engineering;
  - clean, commented, production-ready code;
  - strict error handling and logging for graphics initialisation.
- Decisions:
  - C++20 with `tl::expected`;
  - Windows and Linux only;
  - namespace `playground`, targets `playground_*`;
  - a `Renderer` interface in the render layer, with no Vulkan types above
    render;
  - our own sparse-set ECS;
  - storage buffers read by device address;
  - VMA vendored (v3.3.0) on Linux, vcpkg's on Windows;
  - the camera UBO at set 0, binding 0;
  - reverse-Z;
  - translucent sprites are sorted back to front;
  - one locked job queue;
  - asset decode on workers, finalize on the main thread;
  - **textures are one bindless array (set 1, update-after-bind) with
    default slots 0 (white) and 1 (flat normal)**;
  - **one pipeline layout for every pipeline (sets 0 and 1, one 8-byte
    push constant)**;
  - **GPU resources behind generational handles, freed only after the
    frames using them finish**;
  - **tinygltf and stb used header-only, compiled once in
    `engine/src/GltfImplementation.cpp`**;
  - **demo models are generated by our own script (no third-party art in
    the repository)**.
- Numbering: the user's milestone numbers run ahead of `ROADMAP.md`'s.
- The user may be young or new to this: when asked to explain, keep it short
  and plain, one idea at a time.

**Textures** (`gpu/Image.h`):
- `createTexture(context, {w, h, format R8G8B8A8_SRGB|UNORM, pixels,
  generateMips})` uploads through a staging buffer in one `submitAndWait`:
  - all levels UNDEFINED → TRANSFER_DST;
  - copy into level 0;
  - for each level i: level i−1 TRANSFER_DST → TRANSFER_SRC, then a linear
    blit i−1 → i;
  - levels 0..n−2 TRANSFER_SRC → SHADER_READ_ONLY, and the last level
    TRANSFER_DST → SHADER_READ_ONLY.
- If the format can't blit with linear filtering, it falls back to one
  level with a warning.
- `fullMipCount(w, h) = 1 + floor(log2(max))`.

**Renderer** (`render/src/VulkanRenderer.cpp`):
- `createDescriptorLayouts()` runs before the swapchain:
  - set 0: the frame UBO (vertex and fragment stages);
  - set 1: `COMBINED_IMAGE_SAMPLER[4096]`, PARTIALLY_BOUND |
    UPDATE_AFTER_BIND | UPDATE_UNUSED_WHILE_PENDING;
  - the pipeline layout: both sets plus an 8-byte push constant (vertex
    and fragment).
- `createPipeline()` builds four pipelines with `buildPipeline(spec)`:
  - mesh (back-face culled);
  - double-sided mesh (no culling);
  - opaque sprites;
  - translucent sprites.
- Meshes use vertex input binding 0: `Vertex` {pos, normal, tangent (w =
  bitangent sign), uv}, 48 bytes.
- `createTextureResources()` creates the sampler, an update-after-bind pool
  with one set, and the two 1×1 default textures.
- Each frame:
  1. Wait on the fence.
  2. Acquire an image.
  3. `meshes_/textures_.release(framesPresented_ + 1 − kFramesInFlight)`.
  4. `writeSprites`, then `writeMeshes`: two passes, culled then
     double-sided, writing `MeshDrawGpu` {model, normalMatrix,
     baseColourFactor, (metallic, roughness, normalScale), (texture slots)}
     at 176 bytes. A stale texture handle becomes its default slot; a stale
     mesh is skipped.
  5. `writeFrameUniforms`: viewProjection, cameraPosition, sunDirection,
     sunColour × intensity, ambient (128 bytes).
  6. Record: bind sets 0 and 1, then meshes (`vkCmdDrawIndexed(...,
     firstInstance = i)`), then sprites.
- `ResourcePool<T, Handle>`:
  - slots with generations;
  - `retire(handle, framesSubmitted)` makes the handle stale at once;
  - `release(framesCompleted)` frees the object and the slot.

**Shaders:**
- `mesh_common.glsl` is shared by `#include`; glslc depfiles make shader
  rebuilds follow edits to it.
- `mesh.frag`:
  - base colour × factor;
  - metallic-roughness from B and G;
  - a TBN normal map (`b = cross(n, t) × w`); back faces of double-sided
    materials flip the normal (`gl_FrontFacing`);
  - GGX D, Smith-Schlick G, Schlick F, diffuse `(1 − F)(1 − metallic)
    base/π`;
  - ambient = `ambient × mix(base, F0, metallic)`.

**glTF** (`engine/Gltf.cpp`), decoded on a worker:
- tinygltf `LoadBinaryFromMemory` / `LoadASCIIFromString`, with an image
  hook decoding everything to RGBA8 with stb (thread-safe error messages).
- `extensionsRequired` → `Unsupported`.
- `readFloats<N>` / `readIndices` check every buffer, view and accessor
  range, and handle stride, normalised integers and 8/16/32-bit indices.
  Sparse accessors → `Unsupported`.
- No NORMAL: split the triangles and use flat normals (and ignore any
  TANGENT), as the spec requires.
- No TANGENT: accumulate per triangle (Lengyel) with v flipped, so the
  bitangent points "up the image" as glTF normal maps expect; w comes from
  handedness.
- Nodes: matrix or T·R·S, from the default scene (or every root node), with
  cycle detection; each draw gets its world transform, and bounds are
  computed.
- Non-triangle modes are skipped with a warning; BLEND and MASK alpha modes
  are drawn opaque with a warning.

Uploaded on the main thread by `uploadModel`:
- one mesh per primitive;
- one texture per (image, usage), made on first use: base colour → Colour
  (sRGB); normal and metallic-roughness → Data;
- if anything fails, whatever was already made is destroyed.

`Model` holds the handles and calls `destroyMesh` / `destroyTexture` when
it is destroyed; `extract(transform, frame)` pushes its `MeshInstance`s.

**Camera** (`engine/CameraController.h`):
- Orbit: target, distance, yaw and pitch. Left-drag spins, right-drag pans,
  the wheel and Q/E zoom (multiplicative), WASD or arrows spin and tilt.
- Fly: position, yaw and pitch. WASD moves, Q/E (or Ctrl/Space) moves along
  world up, right-drag looks, Shift ×4, the wheel scales speed.
- Pitch is clamped to ±1.5 rad.
- `setMode` keeps the view; `frame(centre, radius, fov)` fits a sphere.

**Demo:**
- `ModelScene` loads the floor, the crate twice (the second load hits the
  cache) and the spheres, then logs each as ready or failed.
- Tab switches mode, R resets the view.
- With `--model`, the camera frames the model's bounds once it is ready.
- main.cpp calls `assets.clear()` before `application.shutdown()`.

## 3. Code Snippet of the Core Loop/Active Component

`render/src/VulkanRenderer.cpp`, the mesh pass in `recordCommands`:

```cpp
const std::array<VkDescriptorSet, 2> sets{frameSlot.descriptorSet, textureSet_};  // camera+lights, all textures
vkCmdBindDescriptorSets(commands, VK_PIPELINE_BIND_POINT_GRAPHICS, pipelineLayout_.get(), 0,
                        static_cast<u32>(sets.size()), sets.data(), 0, nullptr);
if (!frameSlot.meshCommands.empty()) {
  vkCmdBindPipeline(commands, VK_PIPELINE_BIND_POINT_GRAPHICS, meshPipeline_.get());
  const DrawPushConstants push{.list = frameSlot.meshDraws.deviceAddress()};
  vkCmdPushConstants(commands, pipelineLayout_.get(), kPushStages, 0, sizeof(push), &push);
  VkBuffer bound = VK_NULL_HANDLE;
  for (u32 i = 0; i < frameSlot.meshCommands.size(); ++i) {
    if (i == frameSlot.singleSidedCount) {  // the double-sided run
      vkCmdBindPipeline(commands, VK_PIPELINE_BIND_POINT_GRAPHICS, doubleSidedPipeline_.get());
    }
    const MeshCommand& draw = frameSlot.meshCommands[i];
    if (draw.vertices != bound) {
      const VkDeviceSize offset = 0;
      vkCmdBindVertexBuffers(commands, 0, 1, &draw.vertices, &offset);
      vkCmdBindIndexBuffer(commands, draw.indices, 0, VK_INDEX_TYPE_UINT32);
      bound = draw.vertices;
    }
    vkCmdDrawIndexed(commands, draw.indexCount, 1, 0, 0, i);  // gl_InstanceIndex = i: this draw's MeshDrawGpu
  }
}
```

`gpu/src/Image.cpp`, the mip chain in `createTexture`:

```cpp
for (u32 level = 1; level < mips; ++level) {
  // The level above is finished (copied or blitted): make it the source.
  transitionImage(commands, handle, VK_IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL, VK_IMAGE_LAYOUT_TRANSFER_SRC_OPTIMAL,
                  VK_PIPELINE_STAGE_2_COPY_BIT | VK_PIPELINE_STAGE_2_BLIT_BIT, VK_ACCESS_2_TRANSFER_WRITE_BIT,
                  VK_PIPELINE_STAGE_2_BLIT_BIT, VK_ACCESS_2_TRANSFER_READ_BIT, levels(level - 1, 1));
  const VkImageBlit blit{
      .srcSubresource = {.aspectMask = VK_IMAGE_ASPECT_COLOR_BIT, .mipLevel = level - 1, .layerCount = 1},
      .srcOffsets = {{0, 0, 0}, {mipSize(desc.width, level - 1), mipSize(desc.height, level - 1), 1}},
      .dstSubresource = {.aspectMask = VK_IMAGE_ASPECT_COLOR_BIT, .mipLevel = level, .layerCount = 1},
      .dstOffsets = {{0, 0, 0}, {mipSize(desc.width, level), mipSize(desc.height, level), 1}},
  };
  vkCmdBlitImage(commands, handle, VK_IMAGE_LAYOUT_TRANSFER_SRC_OPTIMAL, handle,
                 VK_IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL, 1, &blit, VK_FILTER_LINEAR);
}
```

`engine/src/Gltf.cpp`, tangents when a file has none:

```cpp
// glTF's v runs DOWN the image while a normal map's green means "up the
// image", so the bitangent the map expects is the direction v SHRINKS.
const glm::vec2 d1{b.uv.x - a.uv.x, -(b.uv.y - a.uv.y)};
const glm::vec2 d2{c.uv.x - a.uv.x, -(c.uv.y - a.uv.y)};
const f32 det = d1.x * d2.y - d2.x * d1.y;
if (std::fabs(det) < 1e-12f) continue;  // no texture stretch to follow
const f32 r = 1.0f / det;
const glm::vec3 tangent = (e1 * d2.y - e2 * d1.y) * r;
const glm::vec3 bitangent = (e2 * d1.x - e1 * d2.x) * r;
// ...summed per vertex, then: t = normalise(t - n * dot(n, t));
// w = dot(cross(n, t), bitangent) < 0 ? -1 : +1
```

## 4. Known Bugs & Incomplete Tasks

No known bugs.

**Found and fixed this session**
- A release-only `-Wnull-dereference` error in `ModelScene` (dereferencing
  `assets.get()` after checking the state). It now tests the pointer itself.
- Two of my test expectations were wrong; in both cases the renderer was
  right. One expected exact colours where bilinear filtering correctly
  blends neighbours; the other used a "flipped" quad whose normals
  disagreed with its winding.
- The worker process restarted twice mid-session; nothing was lost
  (checkpoint commits).

**Not verified**
- A real GPU; Windows. Unverified there: the vcpkg `tinygltf` port's
  `<nlohmann/json.hpp>` include, stb's header location (`find_path` looks in
  `stb/` and directly), MSVC warnings.
- The updated environment setup script, until a fresh session runs it.

**Limitations, acceptable for now**
- Lighting: one sun, a flat ambient term, no shadows, no image-based
  lighting. Metals look dark except at their highlight (visible on the
  demo's gold sphere and the mirror-test panels).
- glTF: no skins, animation, morph targets, cameras, lights, vertex colours,
  second UV set, emissive, KHR material extensions, or per-texture samplers.
  Alpha BLEND/MASK are drawn opaque (with a warning). Required extensions
  (Draco, meshopt, KTX2) are refused.
- Generated tangents are per-vertex averages (Lengyel), close to but not
  exactly MikkTSpace; files with tangents are used as they are.
- Each glTF primitive becomes its own GPU mesh: primitives sharing
  accessors (the demo's 7 spheres) upload the same vertices 7 times.
- One mesh draw per instance (no instancing of repeated meshes, no
  frustum culling); fine for hundreds, not tens of thousands.
- Texture uploads and mesh uploads each `submitAndWait` (a stall on the
  main thread per resource during loading); a transfer queue / batched
  uploads would remove it.
- The bindless array is fixed at 4,096 slots.
- ECS is not used by the 3D scene (objects are a list in `ModelScene`); no
  3D transform component yet.
- Carried over: same-layer opaque sprites z-fight in 3D; sprite buffers
  never shrink; fences, not timeline semaphores; no Vulkan debug names; no
  pipeline cache; GCC sanitizer builds preload the Mesa driver for GPU tests.
