# Aedan's Playground — session handoff

Paste this file into a new session to resume. The plan is `ROADMAP.md`;
build, run and troubleshooting instructions are in `README.md`.

**Status:** reflections are in: **image-based lighting (IBL) and a skybox**,
on top of the 3D geometry and textures milestone (commit `566c459`).
- An environment (a procedural sky, or an HDR panorama loaded from a
  `.hdr` file) is baked on the GPU by four compute shaders into:
  - an environment cube;
  - an irradiance cube;
  - a GGX-prefiltered specular cube.
- A split-sum BRDF table is computed once on the CPU.
- Meshes now get diffuse and specular light from their surroundings, so
  metals reflect the sky.
- A sky pass draws the environment behind everything, with the sun's disk.
- Khronos PBR Neutral tone mapping and exposure are available per frame.
- A fast procedural sky is the default, so headless tests stay quick
  (about 0.2 s per renderer start in a debug build on the CPU driver).
- The 3D demo uses all of it; `--environment PATH.hdr` lights it with a
  photograph.
- Screenshot: `docs/ibl-scene.png` (before: `docs/gltf-scene.png`).

- Repository `colleenneug/Claude-01`, branch `claude/relaxed-cray-5kc2fl`, no pull request open.
- **Long-term goal (user):** Erebus Cradle (the game in `cpp/`) will be moved
  onto this engine eventually; we are still far from that. Roadmap Milestone 5
  covers the port.
- **Environment:** the cloud environment's setup script installs every
  package, including `libtinygltf-dev nlohmann-json3-dev libstb-dev`. Not yet
  proven in a fresh session: if configure cannot find `tiny_gltf.h`, install
  the packages listed in `README.md`.
- Standing guidelines:
  - modern C++20 (smart pointers, RAII, `std::span`, designated initialisers);
  - no over-engineering;
  - clean, commented, production-ready code;
  - strict error handling and logging for graphics initialisation.
- Decisions:
  - C++20 with `tl::expected`;
  - Windows and Linux only;
  - namespace `playground`, targets `playground_*`;
  - a `Renderer` interface, with no Vulkan types above render;
  - our own sparse-set ECS;
  - storage buffers read by device address;
  - VMA vendored on Linux;
  - reverse-Z;
  - asset decode on workers, finalize on the main thread;
  - bindless textures (set 1, binding 0);
  - one pipeline layout for all graphics pipelines;
  - generational handles with deferred freeing;
  - tinygltf and stb compiled once;
  - demo models generated by our own script;
  - **the environment's maps are set 1, bindings 1–4 (irradiance,
    specular, BRDF table, environment)**;
  - **the bake runs on the GPU in compute shaders; the BRDF table is made
    on the CPU**;
  - **the sun's disk is drawn by the sky pass from `FrameData::sun`, never
    baked into the maps** (no double lighting; it follows the light);
  - **lighting and presentation settings in `FrameData` persist between
    frames**;
  - **no third-party art or HDRIs are committed**: Khronos models and an
    sIBL-archive HDR were checked locally only.
- The user's milestone numbers run ahead of `ROADMAP.md`'s.
- The user may be young or new to this: when asked to explain, keep it short
  and plain, one idea at a time.

**The bake** (`render/src/IblBaker.cpp`):
- Creation compiles four compute pipelines with one layout:
  - binding 0: the input (a combined image sampler);
  - binding 1: the output (`image2DArray` rgba16f, one mip of a cube);
  - a 96-byte push constant `BakePush`: the sky colours, sun direction,
    glow, and params (roughness, samples, source size, output size).
- It also creates a clamp-to-edge trilinear sampler, and checks that
  RGBA16F supports storage, blit and linear filtering.
- `bake(ProceduralSky | HdrImage, quality)`. A panorama is first uploaded
  as an RGBA16F texture with mips (floats packed with `glm::packHalf1x16`,
  clamped to 65000 and to ≥ 0). Then one `submitAndWait`:
  1. **Environment cube** (`cubeSize`, full mips).
     - Mip 0 layout UNDEFINED → GENERAL; `bake_sky.comp` or
       `bake_panorama.comp` (the panorama is read at a lod matching cube
       texels); GENERAL → TRANSFER_SRC.
     - Mips 1..n UNDEFINED → TRANSFER_DST; a linear blit chain over all 6
       layers (each level → TRANSFER_SRC once written).
     - All levels → SHADER_READ_ONLY, for the compute and fragment stages.
  2. **Irradiance cube** (`irradianceSize`, 1 mip): GENERAL;
     `bake_irradiance.comp` (cosine-weighted Hammersley, `2 × samples`);
     → SHADER_READ_ONLY.
  3. **Specular cube** (`specularSize`, mips down to 4×4): all levels
     GENERAL; one `bake_specular.comp` dispatch per mip, with roughness =
     mip / (mips − 1); mip 0 copies the environment; → SHADER_READ_ONLY.
  - Descriptor sets come from a per-bake pool; storage views are 2D_ARRAY,
    one mip, 6 layers. Dispatches are ceil(size / 8)² × 6 groups.
- `sampleLod(pdf, count)` in `bake_common.glsl`: filtered importance
  sampling, clamped to the mip with 4×4 faces.
- `validate(quality)`: sizes must be powers of two from 4 to 2048, samples
  1 to 4096.
- Cube face directions follow the Vulkan spec's face table, inverted, in
  `cubeDirection()`.

**The renderer** (`render/src/VulkanRenderer.cpp`):
- Set 1 now has 5 bindings:
  - binding 0: the material array (PARTIALLY_BOUND | UPDATE_AFTER_BIND |
    UPDATE_UNUSED_WHILE_PENDING);
  - bindings 1–4: UPDATE_AFTER_BIND (required in an update-after-bind pool).
  - The pool has 4 extra descriptors.
- `createTextureResources()`:
  - creates the `IblBaker`;
  - makes the BRDF table (`makeBrdfLut(64, 128)`, R16G16_SFLOAT) → binding 3;
  - bakes the default `ProceduralSky{}` at `kFastEnvironment`.
- `installEnvironment()`: `waitIdle`, swap in the new maps, rewrite
  bindings 1, 2 and 4, count the bake.
- `setEnvironment()` = `installEnvironment(baker_->bake(...))`. On error
  the old environment stays.
- `FrameUniforms` (208 bytes): viewProjection, **inverseViewProjection**,
  cameraPosition, sunDirection, sunColour, ambient, **environment**
  (intensity, last specular mip, exposure, toneMap).
- Pipelines: mesh, double-sided mesh, **sky** (no culling, depth test
  GREATER_OR_EQUAL against the far plane, no depth write, no blending),
  and the two sprite pipelines.
- Record order: meshes → sky (if `drawSky`, `vkCmdDraw(3)`) → sprites.

**Shaders:**
- `frame.glsl` holds the shared uniforms, the set 1 environment samplers,
  `toneMapPbrNeutral()` and `present()` (exposure, then tone mapping when
  asked). It is included by `mesh_common.glsl` and the sky shaders.
- `mesh.frag` adds:
  - `diffuse = irradiance(n) × base × (1 − F_rough) × (1 − metallic)`;
  - `specular = specularMap(reflect(−v, n), lod = roughness × lastMip) ×
    (F0 × scale + bias)`;
  - F_rough is Fresnel capped for rough surfaces.
- `sky.vert`: one screen-covering triangle at depth 0; it outputs the
  unprojected near and far points.
- `sky.frag`: direction = far − near, the environment at mip 0, plus the
  sun disk (about 2.5× real size, smoothstep edge).

**Engine and demo:**
- `decodeHdr`: `stbi_loadf_from_memory`, RGBA; warns if the file isn't
  HDR.
- `environmentLoader(renderer, quality = kDetailedEnvironment)` returns
  `EnvironmentAsset{width, height}`.
- `ModelScene`:
  - bakes `ProceduralSky{sunDirection = kSunDirection}` at the default
    quality (128 / 64 / 16, 64 samples);
  - sets `drawSky`, `toneMap`, `environmentIntensity` 1, `ambient` 0;
  - with `--environment`, loads the panorama and logs it as ready or failed.

## 3. Code Snippet of the Core Loop/Active Component

`render/shaders/mesh.frag`, the environment's light (the split sum):

```glsl
vec3 environment = vec3(0.0);
if (frame.environment.x > 0.0) {
  vec3 fresnelRough = f0 + (max(vec3(1.0 - roughness), f0) - f0) * pow(1.0 - nDotV, 5.0);
  vec3 diffuseIbl = texture(irradianceMap, n).rgb * baseColour.rgb * (1.0 - fresnelRough) * (1.0 - metallic);
  vec3 r = reflect(-v, n);
  vec3 prefiltered = textureLod(specularMap, r, roughness * frame.environment.y).rgb;  // mip = roughness
  vec2 scaleBias = texture(brdfLut, vec2(nDotV, roughness)).rg;                     // the CPU-made table
  vec3 specularIbl = prefiltered * (f0 * scaleBias.x + scaleBias.y);
  environment = (diffuseIbl + specularIbl) * frame.environment.x;
}
outColour = vec4(present(direct + ambient + environment), 1.0);  // exposure, then tone mapping if asked
```

`render/shaders/bake_specular.comp`, one texel of one roughness level:

```glsl
for (uint i = 0u; i < count; ++i) {
  vec3 h = frame * importanceSampleGgx(hammersley(i, count), roughness);  // a GGX-distributed half vector
  vec3 l = 2.0 * dot(n, h) * h - n;                                       // n = v = r (split-sum assumption)
  float nDotL = dot(n, l);
  if (nDotL <= 0.0) continue;
  float nDotH = max(dot(n, h), 0.0);
  float d = (nDotH * nDotH * (a * a - 1.0) + 1.0);
  float pdf = max(a * a / (kPi * d * d) / 4.0, 1e-4);
  sum += textureLod(environment, l, sampleLod(pdf, count)).rgb * nDotL;  // wider samples read blurrier mips
  weight += nDotL;
}
store(id, sum / max(weight, 1e-4));
```

`render/src/VulkanRenderer.cpp`, swapping environments safely:

```cpp
Status VulkanRenderer::installEnvironment(Result<EnvironmentMaps> maps) {
  if (!maps) return tl::unexpected(std::move(maps.error()));  // a failed bake keeps the old environment
  if (Status s = context_.device().waitIdle(); !s) return s;  // frames in flight may sample the old maps
  environment_ = std::move(*maps);
  writeEnvironmentBinding(kIrradianceBinding, environment_.irradiance.view());
  writeEnvironmentBinding(kSpecularBinding, environment_.specular.view());
  writeEnvironmentBinding(kEnvironmentBinding, environment_.environment.view());
  ++environmentBakes_;
  return {};
}
```

## 4. Known Bugs & Incomplete Tasks

No known bugs.

**Found and fixed this session**
- Light bled between sky and ground in the irradiance bake: samples near
  the horizon read 1×1 and 2×2 mips, which average both halves of the sky.
  Reads now stop at 4×4 faces, and the red-sky test passes its strict
  check (b < 40) unchanged.
- My own test mistakes: the sky draw wasn't counted in `lastDrawCalls()`
  (now it is), and a test assumed `drawSky` resets each frame. It doesn't,
  by design; that is now documented in `FrameData::clear()`.

**Not verified**
- A real GPU; Windows (see the previous handoff's list: vcpkg tinygltf/stb
  include paths, MSVC warnings).
- The updated environment setup script, until a fresh session runs it.

**Limitations, acceptable for now**
- **No shadows yet.** Objects don't shadow each other or the floor; the
  environment lights everything as if nothing blocked it (no ambient
  occlusion).
- With `--environment`, the scene's directional sun doesn't match the
  photograph's sun (it is game-controlled), and its disk is still drawn.
- `setEnvironment` stalls the main thread (waitIdle plus the bake). Fine
  for loading, not for changing the sky every frame (a time-of-day cycle
  would need incremental re-baking).
- The bake uses fixed sample counts with filtered importance sampling;
  very bright small light sources in a panorama (a sun) can still leave
  faint blotches at low quality.
- HDR panoramas are clamped to the half-float range (65000).
- Tone mapping is per shader (mesh and sky), not a post-process pass;
  sprites are never tone mapped. No bloom.
- Carried over: glTF limits (no skins, animation, alpha blend/mask,
  emissive); one GPU mesh per primitive; one draw per instance, no frustum
  culling; uploads `submitAndWait` per resource; the ECS doesn't hold 3D
  objects; fences, not timeline semaphores; no Vulkan debug names; no
  pipeline cache.
