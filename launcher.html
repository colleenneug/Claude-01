INSTALL THE DESKTOP BUILD

C++17 · OPENGL 4.1 · NATIVE

The same game compiled: physically based shading, cascaded shadows, bloom and depth of field, flown ship to planet to mission. Three commands, then this page can launch it for you.

01 — GET IT AND BUILD IT
git clone https://github.com/colleenneug/Claude-01.git erebus && cd erebus bash tools/install-native.sh
02 — OR BUILD IT BY HAND
cmake -S cpp -B cpp/build -DCMAKE_BUILD_TYPE=Release && cmake --build cpp/build -j
03 — LET THIS PAGE LAUNCH IT
node server/server.js
